# Bug Bounty Corpus — Index

## Purpose
The corpus is the training data for our entire system. Every bug report, methodology guide, CVE, and technique is cataloged here. Prometheus's team continuously processes this corpus to extract patterns, build detection rules, and evolve our tools.

## Sources

### HackerOne Reports
- **Directory**: `corpus/bug-reports/hackerone/`
- **Content**: Disclosed HackerOne vulnerability reports
- **Reference**: https://www.ddosi.org/hackerone-report.html
- **Processing**: Extract vulnerability class, technique, target type, bounty amount

### Immunefi Audits
- **Directory**: `corpus/bug-reports/immunefi/`
- **Content**: Past audit competition results (Web3)
- **Reference**: https://github.com/immunefi-team/Past-Audit-Competitions
- **Processing**: Extract smart contract vulnerability patterns, severity distribution

### Other Sources
- **Directory**: `corpus/bug-reports/other/`
- **Content**: Public disclosures, research papers, security blogs
- **Sources**: CVE database, GitHub Security Advisories, academic papers, conference talks
- **Processing**: Novel techniques, emerging vulnerability classes, tool releases
